# 隐私、配置与故障恢复

## 本地数据

新版 Windows 便携 ZIP 以 exe 同目录的 `portable.flag` 启用便携模式，配置、缓存和日志位于该目录下的 `data/`。旧便携布局继续使用与 `app/` 同级的 `data/`，应用内更新不会迁移它。安装版、开发构建及新 macOS/Linux 原生归档使用 Go `os.UserConfigDir()` 下的 `LiuguangTV`：Windows 通常是 `%APPDATA%\LiuguangTV`，macOS 通常是 `~/Library/Application Support/LiuguangTV`，Linux 通常是 `~/.config/LiuguangTV`（受系统环境配置影响）。便携版不会自动迁移旧数据。

- `state.json`：订阅、频道缓存、收藏、偏好线路、播放器路径及设置。
- `state.json.bak`：日常滚动配置备份。
- `state-corrupt-*.json`：损坏配置的原始副本。
- `import-backups/`：导入前的独立全量恢复快照。
- `epg/`：节目单缓存。
- `logs/diagnostic.log` 及 `.1`、`.2`：本地诊断日志。

配置、缓存及导出 JSON **不加密**，可能包含订阅账号、URL 查询令牌、请求头、本地路径和收藏地址。文件权限不能替代系统账户隔离，配置和播放器进程命令行不宜公开分享。

便携版的 `data/` 位于 exe 同目录下（旧布局为 `app/` 同级），删除整个便携目录会同时删除数据。清理个人数据前应退出应用，并确认不再需要收藏、订阅及恢复快照；不要在整理源码时误删用户数据。

## 配置损坏恢复

保存前将有效配置备份到 `.bak`，备份失败则不写主配置。启动发现损坏时先保留原始字节，再尝试从有效备份恢复；主配置缺失但备份有效时也会恢复并提示。

无法恢复时禁用本次运行的后续保存和自动刷新，避免空状态覆盖数据。手动恢复步骤：

1. 关闭应用，保留当前主文件、备份及损坏副本。
2. 将确认有效的 `state.json.bak` 或导入前快照复制为 `state.json`。
3. 重启并检查订阅和收藏。

不要删除损坏配置后直接在原会话继续保存。导入前快照不会自动清理；确认无需回退后再自行删除。导出格式与运行配置不同，详见 [备份说明](BACKUP.md)。

## 网络访问

应用不预置直播源，不主动上传配置或诊断日志。使用时会访问你选择的服务：

- HTTP(S) 订阅地址，用于下载频道列表及定期刷新。
- EPG 地址，用于获取节目单。
- 当前频道及其清单引用的媒体、密钥和分片服务器。
- 签名发布版本通过 GitHub Releases 检查应用更新，可能下载更新包；开发构建不支持应用内更新。

第三方服务器可获知连接 IP、请求时间、请求头及 URL 内容，并按各自规则处理。HTTP 流量不加密。请只使用可信、合法且有观看权限的来源，谨慎导入他人备份；其中的 mpv 路径会影响后续启动程序。

WebView 的媒体脚本随程序内嵌，不在运行时从 CDN 下载。本机转发服务只监听 `127.0.0.1` 随机端口，以随机令牌隔离页面和会话，不提供任意 URL 代理，不关闭 TLS 验证。具体边界见 [WEBVIEW.md](WEBVIEW.md)。系统 WebView 的缓存和共享进程由系统运行库管理。

## 诊断日志

日志最多 3 个文件，每个 1 MiB，记录固定事件、时间、源地址哈希、错误类别及数值状态码。不记录原始 URL、频道名、请求头、播放器参数或原始异常全文，写入失败会在设置页提示。日志不上传，也不包含完整服务器响应或 mpv 标准错误。

脱敏不代表可以无条件公开所有文件。反馈问题前请检查日志、截图和配置，删除个人信息、令牌和私有地址，不要上传完整配置目录。
