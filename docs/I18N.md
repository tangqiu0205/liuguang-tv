# 国际化

当前支持简体中文（`zh-Hans`）和英文（`en`）。简体中文是源语言和最终回退语言。

## 语言选择

- 应用启动时通过 `mygo.App.SetLanguages("zh-Hans", "en")` 声明支持的语言，默认遵循系统首选语言。
- 设置 → 外观 → 界面语言提供“跟随系统 / 简体中文 / English”三选一。高亮表示已保存的偏好，下方单独显示实际语言。选择通过 `mygo.App.SetLocale` 保存；不在 `state.json` 中维护第二份语言偏好，也不随 JSON 备份导入导出。
- MyGo v0.8.3 没有公开读取语言偏好模式的 API，应用只读它的现有存储：Windows/Linux 的 `locale` 文件、macOS 应用域的 `AppleLanguages`。启动及语言变更时刷新 UI 缓存；读取失败显示错误，不将失败伪装成“跟随系统”。升级 MyGo 时须复核该存储约定。
- MyGo 控件、原生菜单及更新窗口使用同一应用语言；应用链接 MyGo 的 `locales/zh-Hans`，英文由框架自带。
- 语言更改后，原生 UI 重建，窗口标题和当前线路显示名同步更新，不重启播放器。

## 文案约定

`internal/l10n` 是轻量的源文案字典：中文文案本身作为消息 ID（与 gettext 类似），英文译文放在内嵌的 `en.json` 中。运行时不读取外部翻译文件，无需生成代码或新增依赖。

在 `internal/app` 中使用 `tr`：

```go
ui.Text(c, tr("设置"))
message := fmt.Sprintf(tr("订阅 %s 更新完成，共 %d 个频道"), subscription.Name, count)
```

新增文案时：

1. 将应用自有文案包在 `tr(...)` 中，并在 `internal/l10n/en.json` 中添加对应英文。
2. 先翻译格式模板，再插入参数。保留格式参数的类型、数量和顺序（包括 `%w`、`%%`）。
3. 频道名、分组名、订阅名、节目标题、地址和系统错误详情不是翻译键，不要传给 `tr`；只翻译应用自有的前缀或后缀。
4. UI 的 `c.Key` 和持久化值不使用翻译结果。内置“全部分组”通过 `groupTitle` 单独显示译名，实际筛选值不变。
5. 控件的可访问标签、提示、占位符、弹窗和菜单也需要翻译。测试使用中文或英文的标签定位。

查不到译文时保留中文源文案，避免界面出现空白。测试会检查 `tr` 字面量的英文覆盖及格式参数一致性。

## 状态消息与错误

历史状态、提示和缓存错误是生成时的字符串，不对已经插入用户数据的整段内容做反向翻译。切换语言后，已存在的这些消息保留原文，后续消息使用新语言。底层服务及系统错误的原始详情也保持不变。

后台保存、刷新完成的判定兼容两种语言，避免操作期间切换语言导致完成反馈丢失。

## 验证

```bash
go test ./internal/l10n ./internal/app
go test ./...
go vet ./...
go build ./...
```

UI 测试固定源语言以独立于开发机配置，另覆盖英文主界面、筛选、设置页布局、双向语言切换、数据保持，以及跨语言后台完成反馈。真实系统语言偏好持久化和各平台原生弹窗仍需桌面环境人工验证。
