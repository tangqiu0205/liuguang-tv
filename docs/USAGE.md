# 使用指南

## 播放引擎

设置 → 播放器选择 mpv（默认）或内置 WebView。切换引擎会停止当前播放，需重新选择频道，不会在失败时自动换引擎。

### mpv

程序依次寻找手动配置的路径、程序同目录的 mpv、PATH，以及 Windows 当前用户的 Scoop 安装。设置中的路径应为可信 mpv 可执行文件的完整路径，无需额外引号，不支持 VLC 等其他播放器。

Windows 使用专用子窗口嵌入视频，界面统一控制暂停、音量、静音和停止。嵌入模式禁用 mpv 默认键盘绑定和 OSC。

macOS / Linux 使用独立 mpv 窗口，每次启动播放时尝试定位到当前视频区域；不会随主窗口移动、缩放、最小化或设置页同步。Wayland、布局或屏幕信息不可用时回退为普通独立窗口。非 Windows 暂停与音量请使用 mpv 自带控件，不具备应用内 IPC 断流检测和成功线路记录。

### WebView

只负责视频画面，频道、设置与控制仍使用原生 UI。支持无 URL 用户凭据的 HTTP(S) 流，不支持 UDP / RTSP；同频道不兼容线路会被跳过，无兼容线路时明确提示。

- Windows 需要 WebView2 Runtime。
- macOS 使用系统 WKWebView。
- Linux 需要 GTK 3 和 WebKitGTK 4.1（或 4.0）。

编解码取决于系统运行库。不支持的格式请手动改用 mpv。应用不会自动安装运行库；详情见 [WebView 播放](WEBVIEW.md)。

## 订阅与频道库

设置 → 订阅源，点击“添加自定义源”，填写名称和 HTTP(S) 地址，或选择本地 M3U / M3U8 / TXT 文件，再点击“添加并更新”。编辑已有订阅时需点击“保存并更新”才应用草稿。

订阅支持启停、左右排序、删除和单独刷新。停用保留缓存但不参与合并和自动更新；删除移除该源缓存，不删除本地源文件。停用或删除订阅不会强行停止当前流，但后续切线会过滤已不可用的来源。

启动优先显示缓存，每源距离上次检查满 24 小时后后台更新；手动刷新不受周期限制。最多同时加载 3 个订阅，取得槽位后工作超时 30 秒，HTTP 请求超时 25 秒。更新失败保留旧缓存，编辑或删除后的旧请求不会覆盖新状态。

“频道库”标题菜单可选择全部或单个已启用订阅。切源保留收藏筛选，重置搜索和分组，不中断当前播放。所选源删除或停用后回到全部订阅。

放大镜按钮展开名称搜索，再次点击或按 Esc 清空并收起。分组、收藏与订阅筛选共同决定频道列表及上下切台范围。

## 列表格式与请求头

M3U 使用 `#EXTINF` 定义频道，其后为播放地址。单个 HLS 地址应作为频道 URL，不要导入 HLS 分片清单或网页。格式示例见 [channels.m3u](../examples/channels.m3u)。

TXT 按内容识别：

```text
示例分组,#genre#
示例频道,https://example.org/live.m3u8
```

示例地址不可播放。播放地址中的逗号保留；格式错误或不安全的 TXT 地址会拒绝导入并保留旧缓存。

每条线路仅支持 `User-Agent` 和 `Referer`：

1. `#EXTINF` 属性 `http-user-agent="..."` / `http-referrer="..."`。
2. `#EXTVLCOPT:http-user-agent=...` / `#EXTVLCOPT:http-referrer=...`。
3. URL 后缀 `|User-Agent=...&Referer=...`，值使用 URL 查询参数编码，字面加号使用 `%2B`。

优先级为 URL 后缀 > EXTVLCOPT > EXTINF；同层重复字段以后者为准。值最多 4096 字节且不能包含控制字符；Referer 只能是无用户名密码的 HTTP(S) 地址；无效 Referer 会被忽略，频道仍会导入，跳过数量记录在诊断日志中。不执行任意播放器选项、脚本或 Kodi 属性。请求头随线路保存，重复 URL 优先使用排序靠前的已启用订阅及其请求头。

## 多线路与故障恢复

优先按 tvg-id 忽略大小写合并，没有 ID 时按规范化名称匹配；不同非空 ID 或明确不同清晰度保持独立。错误的上游 ID 仍可能导致误合并。

播放线路菜单可手动切换，选中当前线路不会重新播放。优先使用上次确认成功的 URL，否则使用订阅排序中的首条线路。手动切线会开启一轮新尝试。

Windows mpv 与 WebView 使用有限故障切线：启动 20 秒仍未就绪，或播放后连续 30 秒无进展（缓冲宽限 60 秒），尝试剩余启用线路。主动暂停不计失败，每轮每个地址只尝试一次，全部失败后停止。手动停止、切台和退出不会被旧事件触发重播。

## 控制与快捷键

窗口全屏隐藏频道栏和顶部信息栏，让视频铺满当前窗口，不改变窗口尺寸。窗口全屏与系统全屏统一使用深色界面及底部居中的圆角控制栏，最大宽度 760 DIP、高度 56 DIP，距底边 16 DIP；窄窗口自动缩短并收起部分操作。两个模式均不显示顶部信息栏。

Windows 下鼠标静止约 3 秒后隐藏控制栏，移动鼠标可重新显示；鼠标停在控制栏、节目单打开或没有播放时保持显示。mpv 原生视频仅在圆角控制栏所在区域避让，两侧和下方继续显示视频，不裁掉整条底边，也不改变视频尺寸。控制栏隐藏后恢复完整视频区域。其他平台保留控制栏；非 Windows 的 mpv 仍使用独立窗口。

可通过控制栏按钮或 Esc 退出；从窗口全屏进入系统全屏，退出系统全屏后恢复窗口全屏。顶部不显示节目摘要和节目单入口，需要浏览节目单时可先退出全屏。

主界面持有焦点时：

| 按键 | 操作 |
| --- | --- |
| Space | 暂停 / 继续（mpv 仅 Windows） |
| ← / → | 音量 -5 / +5（mpv 仅 Windows） |
| ↑ / ↓ | 按当前筛选切台，到两端后循环 |
| F11 | 切换系统全屏 |
| Esc | 退出全屏 / 窗口全屏或收起搜索 |

设置页、搜索展开、配置迁移或文件对话框期间禁用播放快捷键，不注册全局热键。视频持有焦点时请先点回原生界面，或使用控制按钮。

## EPG 节目单

优先读取 M3U 头部的 `x-tvg-url` / `url-tvg` / `tvg-url`，支持多个 HTTP(S) XMLTV / gzip 地址；设置 → 订阅源底部可填写备用网络地址或本地文件。

EPG 每源每 24 小时检查更新，失败保留缓存和成功时间。最多并发 3 个任务，取得槽位后超时 1 分钟；下载和解压后均限制 64 MiB。支持手动刷新全部或单源刷新。

优先使用频道所属订阅中有当前节目的节目源，其次备用源；无当前节目时优先未来节目。先按 tvg-id 匹配，再按规范化名称；同名存在多个 ID 时不猜测。播放顶栏和节目面板跟随实际播放线路，而非频道库筛选。

点击“节目单”浏览实际有数据的日期。时间按 XMLTV 偏移解析，无偏移使用 UTC，按本机时区展示；跨午夜节目可出现在多个日期。不支持节目回看或手动频道绑定。

节目保留最近 7 天至未来 14 天。缓存位于配置目录 `epg/`，后台定期清理，也可手动清理：停用 / 移除源超过 7 天、仍使用的缓存超过 30 天、遗留临时文件超过 1 天时删除，仅处理自有文件名。

设置页包含订阅源、播放器、外观、备份、关于。外观支持跟随系统、日间和夜间；mpv 路径草稿需点击保存才应用，引擎选择立即保存。
