# 订阅链接备份

## 导出范围

入口：设置 → “备份”标签。导出与恢复分区展示，恢复会整份覆盖、不合并。导入成功后，备份页面显示最近一次恢复快照路径。运行配置位置及损坏恢复见 [隐私与数据](PRIVACY.md)。

默认文件为 `LiuguangTV-backup.json`，只包含：

- HTTP(S) 网络订阅的链接、名称、顺序与启停状态。
- 收藏、偏好线路、主题、播放器路径及备用 EPG 设置。

**不包含本地 M3U/M3U8/TXT 订阅、无链接历史频道、频道缓存、源文件本体、视频、EPG XML 缓存、日志或 mpv 程序。**

存在本地或历史订阅时，导出前会显示排除的数量并要求确认。没有网络订阅也可导出仅含收藏和设置的文件，但不会伪称已经备份本地频道。本地源文件即使已删除也不影响导出，因为备份不读取它；请自行保管本地文件，需要时重新导入。

收藏和偏好仍可能含来自本地频道的播放地址或标记，它们是用户设置，不包含源文件内容或完整频道列表。原来选中的订阅被排除后，备份将选择恢复为“全部订阅”。

## 格式与校验

JSON 使用 `format: "liuguangtv-config"`、`version: 3`，`state` 存放轻量配置。仅接受当前版本的 JSON；不兼容旧版全量 JSON、ZIP 或直接复制的运行配置。

- 导入/导出分别限制 64 MiB。
- 校验订阅 ID 唯一性、HTTP(S) 链接、收藏与设置的结构。
- 拒绝本地/无链接订阅、频道缓存及未知字段；订阅刷新时间与旧错误不会阻止重新拉取。
- 拒绝多余 JSON 文档和未知格式/版本，不按后缀猜测格式。
- 导出失败不覆盖已有目标；目标不能是运行配置、滚动备份或当前本地订阅源文件。

## 导入和恢复

导入前先只读验证，不访问订阅网络；确认后**整份覆盖、不合并**，包括移除当前配置中的本地订阅和历史频道，但不删除其源文件。界面会明确提醒这一点。

提交时先排空旧写入，将旧完整配置同步保存到 `import-backups/state-before-import-*.json` 唯一命名快照，再写入新配置。只有全部成功后才替换当前会话、停止旧播放并取消旧下载。快照或写盘失败时保留旧会话和播放。

应用新配置后，启用的网络订阅重新拉取频道；停用订阅不会自动下载。网络不可用时显示更新失败，不伪造已恢复频道。本地订阅需用户自行重新导入。

独立快照是原始全量 `state.json`，包含缓存及路径，不参与 `.bak` 轮换，也不受后续导入覆盖。回退前关闭应用、备份当前配置，将确认有效的快照复制为 `state.json` 后重启。快照不含本地源文件本体，需要读取本地源时仍须保留它；程序不会删除已有的源文件目录。

运行中的 `state.json`、`state.json.bak` 和独立快照仍保留全量缓存用于本机故障恢复，不是轻量迁移备份。旧快照可能含本地路径和敏感地址，不自动清理，确认不再需要后可自行删除。

## 隐私

JSON 没有加密。网络订阅、收藏和偏好可能含账号、令牌或播放地址，请妥善保管。只导入可信备份，播放器路径会影响后续启动程序。mpv 和本地备用 EPG 路径在换电脑后可能需要调整，相关文件不会被备份。
